
# Linux System Health Monitoring

## Overview
A Bash automation project to collect basic
Linux server health information.

## Problem
Administrators need a quick way to inspect
system health during troubleshooting.

## Features
- Hostname and uptime checks
- Memory usage
- Disk utilization
- Top CPU-consuming processes

## Technologies
Linux, Bash, Ubuntu, RHEL

## How to Run
```bash
chmod +x system-health.sh
./system-health.sh
```

## Future Improvements
- Disk usage threshold alerts
- Log file generation
- Email notifications
- Cron-based scheduling
